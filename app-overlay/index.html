اسکور بورڈ کا لنک

آپ کا دیا ہوا لنک پہلے سے شامل ہے

اگر ویب سائٹ iframe کی اجازت نہ دے تو اسکور بورڈ الگ ٹیب میں کھلے گا۔ اس کا مطلب یہ نہیں کہ ویڈیو خودکار طور پر نشر ہو رہی ہے۔
2

اسٹریمنگ کے چینلز

اپنے چینلز کی تفصیلات درج کریں

Stream Keys پاس ورڈ کی طرح خفیہ رکھیں۔ یہ صرف اسی موبائل کے browser storage میں محفوظ ہوں گی؛ کسی کو نہ بھیجیں۔
3

لائیو نشریات

براہِ راست نشریات کی تیاری

اسٹریمنگ انجن منسلک نہیںیہ کنٹرول پینل ہے؛ RTMP relay/server درکار ہے۔

Start بٹن ابھی بند ہے کیونکہ اس پیکج میں RTMP ویڈیو انجن یا کلاؤڈ سرور شامل نہیں۔ صرف Stream Keys درج کرنے سے لائیو شروع نہیں ہوتی۔
